## SDD Analysis Gate

**REQUIRED before implementation**: Check that `analysis.md` exists in the active feature directory with zero CRITICAL findings.

### Feature Directory Resolution

Determine the active feature directory using this precedence:
1. Extract from current git branch: `git symbolic-ref --short HEAD 2>/dev/null` — if branch matches `feature/<id>` or `feat/<id>`, use `specs/<id>/`
2. If only one directory exists under `specs/`, use that
3. Only as last resort (single-feature repo): `ls -d specs/*/ 2>/dev/null | tail -1`

```bash
branch=$(git symbolic-ref --short HEAD 2>/dev/null || echo "")
feature_id=$(echo "$branch" | sed -n 's|^feat\(ure\)\?/||p')
if [[ -n "$feature_id" && -d "specs/$feature_id" ]]; then
    feature_dir="specs/$feature_id/"
elif [[ $(ls -d specs/*/ 2>/dev/null | wc -l) -eq 1 ]]; then
    feature_dir=$(ls -d specs/*/ 2>/dev/null)
else
    feature_dir=$(ls -d specs/*/ 2>/dev/null | tail -1)
fi
```

### Gate Check

```bash
grep -q "<!-- Result: CLEAR -->" "${feature_dir}analysis.md" 2>/dev/null && echo "CLEAR" || echo "BLOCKED"
```

If `analysis.md` is missing or does not contain `<!-- Result: CLEAR -->`:
- **STOP**. Do not proceed with implementation.
- Instruct the user: "CRITICAL findings must be resolved before implementation. Run `speckit.analyze` to see what needs to be fixed."

## Feedback Trigger (MANDATORY)

`speckit.feedback` is part of the SDD loop. At the end of every implementation run, exactly **one** of three feedback types fires based on what happened:

- **End of feature** (final checkpoint passed OR last Polish task completed) → fire `end-of-feature`. Highest priority — takes precedence over the others.
- **Story-Complete Review Gate passed in this run** → fire `story-complete`. Captures friction at the natural story boundary.
- **One or more tasks completed but no checkpoint hit** → fire `session-end`. Captures friction at the working-session boundary.
- **No tasks completed** (stopped on a question, blocker, or pre-flight failure) → skip entirely. Nothing useful to record.

The agent MUST invoke the appropriate `speckit.feedback` command automatically without waiting for the user to ask.
